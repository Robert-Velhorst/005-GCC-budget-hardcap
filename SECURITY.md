# Security Policy

This file is GitHub's security-policy entry point for this repository. See [the detailed project security policy](docs/SECURITY.md) for repository-specific security controls and operational requirements.

## Supported versions

Security reports for the current default branch and the latest published release are in scope. Older versions may be affected and are not guaranteed to receive fixes.

## Reporting a vulnerability

Do not publish vulnerability details, secrets, proof-of-concept code, or exploit instructions in a public issue, discussion, or pull request. If GitHub shows **Report a vulnerability** in this repository's Security tab, use that private reporting form.

If private reporting is unavailable, contact the repository maintainers through a private contact method listed on the repository owner's GitHub profile. If none is available, open an issue asking for a private disclosure channel and include no vulnerability details until a private channel is available.

## Response and disclosure

Reports are reviewed on a best-effort basis. No response or fix-time guarantee is provided. Coordinate public disclosure with the maintainers so users have a reasonable opportunity to receive a fix.
